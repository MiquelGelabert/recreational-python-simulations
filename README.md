Welcome to my recreational coding hub! This repository is a collection of games, puzzles, and mathematical simulations developed as part of my journey in Python programming. 

## About this Project 🚀

These projects represent my passion for logic and problem-solving. Beyond just creating games, I used these exercises to understand **statistical distributions, game theory, and competitive modeling**. Each file is a step forward in my learning process, showing my enthusiasm for turning abstract logic into interactive code.

## What's Inside? 📂

The repository is organized into different types of challenges:

### 🎮 Classic Logic Games
* **Wordle Solver & Game:** A Python version of the popular word game with a built-in suggestion system to help find the secret word.
* **Minesweeper (Buscaminas):** Implementation of the classic grid-based logic game, focusing on matrix manipulation and recursive clearing logic.

### 📊 Mathematical & Strategic Simulations
* **Prisoner's Dilemma (Dilema del Prisionero):** A simulation of this classic Game Theory scenario. It includes different player strategies (random, tit-for-tat, etc.) and visualizes the long-term results of cooperation vs. defection.
* **Chess Elo Simulation:** A notebook that models the Elo rating system used in competitive games to calculate relative skill levels and predict match outcomes.
* **Number Guessing Statistics:** An analysis of the "Guess the Number" game. It uses the **Binary Search** concept to demonstrate why the number of attempts follows a logarithmic curve ($log_2 N$).

## Key Concepts Explored 💡
- **Game Theory:** Strategic interaction between rational players.
- **Probability & Statistics:** Analyzing outcomes and digit/attempt distributions.
- **Algorithms:** Binary search, recursive logic, and matrix handling.
- **Data Visualization:** Using `matplotlib` to see the "why" behind the results.
